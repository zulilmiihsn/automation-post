## ⚡ Overview

**Automation Post** is a fullstack automation platform designed to manage high-volume multi-account Facebook Marketplace listings, automated group broadcasting, auto-bumping (*sundul*), and AI-generated dynamic response copywriting with anti-bot stealth protection.

---

## 🌟 Core Capabilities

- 🛡️ **Playwright Stealth Engine**: Anti-detection browser automation using `puppeteer-extra-plugin-stealth` and humanized interaction curves.
- 🧠 **Groq AI Copywriting Agent**: Real-time contextual copy generation for product listings and group marketing engagement.
- 🗄️ **Multi-Account & Group Management**: Account health monitoring, proxy rotation readiness, and group mirror mapping.
- ⏱️ **Intelligent Sundul & Scheduler**: Configurable cron-based auto-bump engine with rate limit protection and quiet hours.
- 🖥️ **Full React Operator Dashboard**: Live execution console, analytics page, dynamic attribute editor, and media gallery.
- 🧪 **Comprehensive Test Suite**: End-to-end coverage for database operations, API contracts, orchestrator logic, and scheduler reliability.

---

## 🛠️ Technology Stack

- **Automation Engine**: `Playwright`, `Playwright-Extra`, `Puppeteer Stealth Plugin`
- **AI Intelligence**: `Groq API`, Contextual LLM Prompting
- **Backend API**: `Node.js`, `Express 5`, `better-sqlite3`, `node-cron`, `multer`
- **Frontend Dashboard**: `React 18`, `Vite`, `CSS Modules / Tailwind`, `Lucide Icons`
- **Database**: `SQLite 3` (WAL Mode enabled)
